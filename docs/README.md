# CAREWSM active documentation

This directory contains the active CAREWSM management and research contract.

The old WSM task history, progress ledgers, stage plans, evidence files, paper artifacts, and agent-generated research summaries were intentionally removed from the CAREWSM working tree. They are not authoritative for this project.

Read in order:

1. `PROJECT_REQUIREMENTS.md`
2. `PLAN.md`
3. `PROGRESS_EN.md`
4. `NEXT_TASK_EN.md`
5. `MANAGER_CONTRACT.md`
6. root `AGENTS.md`

Project facts discovered by audit must be separated from owner-provided assumptions. When they conflict, the manager reports the discrepancy and updates the active contract deliberately.
